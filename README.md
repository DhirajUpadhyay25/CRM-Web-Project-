# CRM-Web-Project-
Developed a CRM (Customer relationship management) system using Java, Spring Boot, MVC architecture, Hibernate/JPA, SQL, REST APIs, and Razorpay for managing courses, users, employees, and payments.
EduTech CRM Web Application (Backend)
Built a CRM system using Java, Spring Boot, Hibernate/JPA, SQL, REST APIs, and Razorpay to manage courses, users, employees, and payments. Implemented role-based authentication and authorization with Spring Security, developed modular backend architecture (Controller-Service-Repository), integrated secure online payments via Razorpay, and optimized database operations for improved performance and scalability.
